# Joshua 24:15 Daily Dashboard

A GitHub Pages-ready Week 5 dashboard for Joshua 24:15 (NiRV) and target vocabulary. It includes Bible-verse listening and three-round reading drills, verse word-order practice, verse comprehension quizzes, vocabulary practice, three-round vocabulary drills, and a vocabulary game.

## Publish with GitHub Pages

1. Create a repository on GitHub.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.

The site has no dependencies or build requirements. Reading progress is saved locally in the learner’s browser.
